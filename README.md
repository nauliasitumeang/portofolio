🔗 **Live site:** https://nauliasitumeang.github.io/portofolio/

## What's inside

- **About:** a short introduction and the skills & tools I use
- **Work:** CTF writeups from the GDGoC USU Cybersecurity Pathway
- **Certificates:** certificates and achievements I've collected so far
- **Contact:** a quick way to reach me

## Built with

HTML, CSS, and vanilla JavaScript. No frameworks!

## Vibe coding

This website was built through vibe coding: I described the look and feel I wanted, worked with an AI assistant to generate and refine the code, then tested, tweaked, and debugged it myself along the way until it suit to my taste. It's a project where I learned by building and fixing things, not by copy-pasting blindly.

## Deployment

The site is hosted for free with **GitHub Pages**:

1. Push the project to a GitHub repository
2. Open **Settings → Pages**
3. Under **Build and deployment**, set the source to **Deploy from a branch**, then choose the `main` branch and the `/ (root)` folder
4. Save, and wait a minute or two for the site to go live
5. Every time I push a new commit, GitHub rebuilds the site automatically

## Run it locally

1. Clone this repository
2. Open the folder in VS Code
3. Run `index.html` with the Live Server extension
